# 第一次使用

只在 `status --verify` 显示未配置或密钥失效时读取。一次只说一步，等待用户完成后再继续。

## 第一步

对用户说：

```text
请先在曼格云控制台创建 API Key。密钥只显示一次，请先安全保存；不要把它写进前端代码、日志或公开仓库。完成后告诉我“好了”。
```

## 第二步

用户说“好了”后，对用户说：

```text
请把 API Key 配置为本机环境变量 WE_MEDIA_API_KEY。配置好后告诉我“已配置”，不要把密钥发到聊天里。
```

如果用户明确要求由 AI 代为保存，才运行脚本 `setup`，让用户在本机隐藏输入中粘贴；保存位置为技能目录中被 `.gitignore` 忽略的 `.env`。不要通过命令参数传递密钥。

## 第三步

运行 `status --verify`。成功后只回答：

```text
已经配置好。告诉我公众号名称，以及要最近几篇、指定日期范围，还是全部历史。
```

不得回显密钥或把验证请求头写入输出。
